## 🌐 Free Hosting & Deployment Options

### 1. GitHub Pages (Automated)
1. Push this folder to a new GitHub repository (e.g. `portfolio_leanmorandante`).
2. Go to repository **Settings > Pages**.
3. Under **Build and deployment > Source**, select **GitHub Actions**.
4. The included [`.github/workflows/deploy.yml`](file:///c:/Users/Mark%20Lester/OneDrive/Desktop/portfolio_leanmorandante/.github/workflows/deploy.yml) will automatically build and publish your site at `https://<username>.github.io/<repo-name>/`.

### 2. Vercel (1-Click)
1. Import repository on [Vercel](https://vercel.com).
2. The included [`vercel.json`](file:///c:/Users/Mark%20Lester/OneDrive/Desktop/portfolio_leanmorandante/vercel.json) handles caching and clean URLs automatically.

### 3. Netlify (Drag & Drop)
1. Drag and drop this folder onto [Netlify Drop](https://app.netlify.com/drop).
2. The included [`netlify.toml`](file:///c:/Users/Mark%20Lester/OneDrive/Desktop/portfolio_leanmorandante/netlify.toml) applies security and asset caching headers.
